# 🤖 Desafio: Ranking de Vendedores

**Contexto:** Uma empresa deseja descobrir quem vendeu mais durante o mês.
**O que fazer:** Crie um vetor de objetos para receber os nomes dos vendedores cadastrados e, posteriormente, as vendas deles.

*Utilize métodos de array* para:
* Montar o Ranking com os 3 que mais venderam.
* Calcular o total de vendas.
* Calcular a média de vendas.
* Exibir todos os vendedores cuja venda ficou acima da média.

- Funções;
- Vetores e métodos de vetores;
- Objetos;
- Strings e funções de strings;
- Condicionais;
- Eventos, etc;
